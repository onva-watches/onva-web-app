# ONVA - Watchmaking Business Operating System

A modern, mobile-first web application for independent watchmakers to manage repair workflows, track profitability, and streamline operations.

## Features

- **Repair Workflow Management** - Track jobs from intake to delivery
- **Financial Dashboard** - Monitor revenue, expenses, and profitability
- **Client Management** - Organize customer information and history
- **Labor Tracking** - Log hours and calculate costs per job
- **Notion Integration** - Real-time sync with your Notion workspace
- **Mobile-First Design** - Works perfectly on iPhone, iPad, and desktop

## Getting Started

### Prerequisites
- Node.js 16+
- npm

### Installation

```bash
npm install
npm start
```

The app will open at `http://localhost:3000`

### Build for Production

```bash
npm run build
```
